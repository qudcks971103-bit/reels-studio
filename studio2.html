자동 저장

글자·틀·스타일 설정은 IndexedDB에 자동 저장돼요. 영상 파일 자체는 브라우저에 저장되지 않아 다시 고르셔야 해요.

⚙️ 설정

YouTube 연결

Google Cloud 콘솔 → API 및 서비스 → 라이브러리에서 YouTube Data API v3 사용 설정 → OAuth 클라이언트 ID(웹 애플리케이션)를 만들고, 승인된 자바스크립트 원본에 이 앱 주소를 넣어 주세요. ID는 이 기기에만 저장돼요.

⚠️ 지금은 파일(file://)로 열려 있어요. Google 로그인은 https:// 주소나 http://localhost 에서만 동작해요. 편집·저장은 파일로도 그대로 됩니다.

이 기기의 저장 형식 (코덱 점검)

MP4 · H.264로 저장돼야 인스타그램·유튜브에 바로 올라가요. WEBM만 되면 아이폰 사파리에서 열어 다시 만들어 주세요.
