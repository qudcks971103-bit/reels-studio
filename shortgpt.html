최근 연결

    서버 주소는 어디서 얻나요?
    1. 내 PC에서 실행: ShortGPT 폴더에서 python runShortGPT.py 실행 → 같은 와이파이의 폰에서 http://PC의IP:31415 입력
    2. 외부(LTE)에서도 쓰려면: gui/gui_gradio.py의 share=self.colab를 share=True로 바꾸고 실행 → 터미널에 나오는 https://….gradio.live 주소 입력 (72시간마다 바뀜)
    3. Google Colab: 저장소의 Colab 노트북을 실행하면 나오는 gradio.live 주소 입력
    4. 화면이 비어 보이면 새 창 버튼으로 여세요. (일부 서버는 다른 페이지 안에 표시되는 것을 막습니다)
    홈 화면에 추가하는 법
    1. 아이폰(Safari): 공유 버튼 → 홈 화면에 추가
    2. 안드로이드(Chrome): ⋮ 메뉴 → 홈 화면에 추가
